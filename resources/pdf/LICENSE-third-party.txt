Third party files in this directory
===================================

github-markdown.css
-------------------
github-markdown-css 5.9.0 by Sindre Sorhus, https://github.com/sindresorhus/github-markdown-css
Update with:

    curl -o resources/pdf/github-markdown.css \
         https://unpkg.com/github-markdown-css@5/github-markdown.css

alert_note.svg, alert_tip.svg, alert_important.svg, alert_warning.svg, alert_caution.svg
----------------------------------------------------------------------------------------
GitHub Octicons, https://github.com/primer/octicons
They were taken from the HTML that https://api.github.com/markdown returns for an
alert in mode "gfm", see the comment in bin/make_pdf.sh for the exact command.
